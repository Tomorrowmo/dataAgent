> ★ 注意两个「数据集」是不同东西：
> - **🗂 数据集（一级图标）** = 管理你的数据（上传/预览/清洗/血缘）。
> - **算法页里的「用哪份数据」下拉** = 临时挑一份数据来跑/测这个算法，嵌在表单里，不是单独的地方。

## 细节 · 彩色字母头像

每个会话名前一个**圆角方块**：底色由会话 id 哈希（每个会话固定一色），里面是标题首字。

```
┌──┐  ┌──┐  ┌──┐  ┌──┐        像 Notion/Linear：
│电│  │映│  │批│  │A │        一眼能区分、整列很整齐好看
└──┘  └──┘  └──┘  └──┘
 蓝    紫    绿    橙
```

`● 刚刚` 那个小圆点 = 当前选中/有未读的会话。
