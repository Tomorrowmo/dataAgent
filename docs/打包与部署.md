# RLab Cortex 打包与部署

本项目提供两种 Windows 分发方式。**改完前端或后端代码后，重跑对应命令即可出新包。**

构建命令都在项目根目录下执行（PowerShell）。

---

## 一、免安装完整包（推荐给客户 / 别人的机器）

客户**什么都不用装**（Python、Node、依赖全部打包在内）：解压 → 双击 `start.bat`。

**重建命令：**

```powershell
powershell -ExecutionPolicy Bypass -File tools\package_windows_full.ps1
```

- 产物：`dist\RLab Cortex-免安装-win64.zip`（约 **1.3 GB**，仅限 Windows 64 位）
- 构建前置（**本机**，不是客户机）：联网 + 本机已装 Node（脚本会下载嵌入式 Python / 便携 Node / Caddy，并 `pip install` + `npm install` + 生产构建）
- 构建耗时：几分钟（下依赖 + 构建 + 压缩）
- 脚本：[tools/package_windows_full.ps1](../tools/package_windows_full.ps1)；其中的启动脚本等资产在 [tools/win_full_assets/](../tools/win_full_assets/)

**包内结构：**

```
RLab Cortex\
  runtime\python\   自带 CPython 3.12 + 全部后端依赖
  runtime\node\     自带便携 Node
  backend\          后端源码 + requirements + .env.example + data\(空)
  web\              前端源码 + 预装 node_modules + 预构建 .next
  caddy\            caddy.exe + Caddyfile（公网域名反代，可选）
  start.bat  stop.bat  serve-domain.bat  使用说明.txt
```

**客户机使用：**
1. 解压到**可写目录**（桌面 / D 盘；**不要**放 `C:\Program Files`，那是只读的）
2. 双击 `start.bat` → 自动启动并打开 http://localhost:3000（首次后端冷启动约 10~30 秒）
3. 停止：`stop.bat`

## 二、轻量源码包（自己 / 内部，目标机能联网装环境）

不打包运行时，体积极小；目标机需**先装 Python 3.11+ 和 Node 18+**，再跑 `setup.bat` 联网装依赖。

**重建命令：**

```powershell
powershell -ExecutionPolicy Bypass -File tools\package_windows.ps1
```

- 产物：`dist\RLab Cortex-portable.zip`（约 **0.3 MB**）
- 客户机：装好 Python + Node → 解压 → `setup.bat`（联网装依赖+构建，3~8 分钟）→ `start.bat`
- 脚本：[tools/package_windows.ps1](../tools/package_windows.ps1)

## 三、通过公网域名访问（两种包都支持）

架构：`浏览器 https://域名 → Caddy(:80/:443) → 前端(:3000) → /api 转发 → 后端(:8077)`

前提（**缺一不可**）：
1. 这台机器有**公网 IP**，且 **80 与 443** 对公网开放（Windows 防火墙 + 路由器都放行）
2. 域名的 **A 记录**指向该公网 IP

步骤：
1. 先 `start.bat` 把应用跑起来（:3000）
2. **右键 `serve-domain.bat` →「以管理员身份运行」**，按提示输入域名
   - 免安装包已内置 `caddy.exe`；轻量包首次会自动下载
   - Caddy 自动申请并续期 Let's Encrypt 证书
3. 浏览器打开 `https://你的域名`

若机器在内网 / NAT 后面没有公网 IP：需先做 80/443 端口映射，或用内网穿透（Cloudflare Tunnel / frp 等）把域名引到本机。

## 四、其它说明

- **AI 功能**（解析未知格式 / AI 解释 / 对话分析）需大模型：进应用后注册账号 → 「设置」里填一个模型 API Key（DeepSeek 或任意 OpenAI 兼容）。不填也能用：导入数据、自动「认识这份数据」、内置算法、数据表预览/排序/筛选、示例数据与流程。
- **数据**都在 `backend\data\`（SQLite + 上传文件），备份/迁移直接拷该目录。新实例的新账号自动带示例数据集与示例流程。
- **网格 / CFD 文件**（`.cgns/.vtk/.stl`）需要 `pyvista`（含 VTK，体积大），默认未打包。需要时：
  - 免安装包：`runtime\python\python.exe -m pip install pyvista`
  - 轻量包：`backend\.venv\Scripts\python -m pip install pyvista`
  - 只用 CSV / Excel / Parquet / Tecplot(.dat) 不需要它。
- **Linux 服务器 / Docker** 部署见 [deploy/](../deploy/)（docker-compose.yml + Dockerfile + nginx.conf）；线上阿里云用的是 systemd + nginx。
- **首次启动很慢**：多半是 Windows Defender 在扫运行时目录，管理员 PowerShell 跑一次永久解决（路径换成实际解压路径）：
  - 免安装包：`Add-MpPreference -ExclusionPath "解压路径\runtime"`
  - 轻量包：`Add-MpPreference -ExclusionPath "解压路径\backend\.venv"`
