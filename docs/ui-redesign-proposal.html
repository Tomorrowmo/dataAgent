01 方案总览
R RLab Cortex · 界面改版方案 · v2 草案（工程向）

计算书式的工程界面

使用者是工程背景的人，服务的是工程领域。所以界面按工程软件的习惯来做：中性灰底板，内容是一页页白色"计算书"，颜色只表示状态。不靠渐变、光晕和大圆角制造"科技感"，而是靠精确的数字、明确的单位和随处可见的来源标注，让工程师一眼看出：这个结果从哪来、能不能复现、能不能拿去汇报。

02

设计概念：底板 + 计算书

底板（#F3F4F6）是唯一的背景色，中性冷灰，不带黄红倾向。布局保持现状（图标栏 + 会话面板 + 主区 + 工作台）。图标栏和会话面板共用底板色，主区为白色，之间只用 1px 细线分隔，所以不会割裂。

计算书（#FFFFFF）承载内容：对话结果、数据表、算法编辑器。每个结果像一页计算书，写清输入、方法、结论和单位。计算书之间用 8–12px 的底板间隙隔开，边界是 1px 细线，几乎不用阴影。

墨蓝（#2B4C6F）是唯一的主色，只给"主操作"和"当前选中"。其余颜色全部是有含义的状态色。

颜色 = 状态。红表示错误或报警，琥珀表示警告，绿表示通过，蓝表示进行中，正常状态不着色（参照工业 HMI 的 ISA-101 思路）。AI 生成的内容不占颜色，用虚线框加"AI"字样标注，避免和警告色混淆。

03

五条设计原则

P1
结果优先
图表、表格、数值放在最显眼处；思考过程和调用步骤默认折叠。
P2
来源可见
每个结果都带一行来源：算法、版本、参数、耗时。内置 / 自定义 / AI 生成用形状和颜色同时区分。
P3
颜色有含义
一个主色、四个状态色。AI 标记靠形状和文字，不占颜色。不出现只为好看的颜色。
P4
数字可读
数值用等宽数字、右对齐，必须带单位；有效位数统一，可切换科学计数法。
P5
安静的界面
层级靠留白与细线，不靠阴影、渐变和动效。动效只用于状态变化，≤150ms。
04

面向工程用户的六条约定

参照工程师日常用的软件（MATLAB、ANSYS、SCADA/HMI、Grafana）：底色中性、信息密度高、数字精确、结果可追溯。

单位与精度表头写成"压力 (MPa)"，坐标轴必须标单位；有效位数全局统一、可设置；支持千分位与科学计数法；时间戳到秒并标时区。
信息密度提供"标准 / 紧凑"两档，表格默认紧凑（行高 24px）。参数面板与结果并排，不用一步一步的向导。常用操作有快捷键。
颜色只表示状态红 = 错误 / 报警，琥珀 = 警告，绿 = 通过，蓝 = 进行中；正常状态保持灰色。状态色不挪作装饰。
可追溯、可交付每个结果带编号、版本、输入、参数、方法；一键导出计算书（PDF / Word），附原始数据 CSV 和参数记录。
能打印、能投影默认浅色主题；图表系列同时用颜色和线型（实线 / 虚线 / 点划）区分，黑白打印和色弱用户都能分辨。
陈述式文案写"拟合完成：R² = 0.973，n = 1,248"，不写"✨帮你搞定啦"。不用 emoji，不说"智能""魔法"。
