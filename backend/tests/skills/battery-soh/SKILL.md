# 电池 SOH 评估

适用于每行一个循环、含循环序号与放电容量两列的电池循环测试数据。

## 步骤

1. 先用 `outlier_detect`（IQR）检测容量列的异常循环，异常点不参与后续计算，并在结论里列出被排除的循环号。
2. 用 `soh_curve` 工具计算每个循环的 SOH：以前 5 个有效循环的容量中位数作为初始容量 C0，SOH = 容量 / C0 × 100%。
3. 报告最后一个循环的 SOH，以及 SOH 首次低于 80% 的循环（寿命终点 EOL）；如果数据范围内还没到 80%，明确说"尚未到达"，不要外推成确定值。
4. 画出 SOH 随循环变化的折线图，标出 80% 参考线。

## 注意

- 寿命终点按行业惯例取 SOH = 80%，除非用户另行指定。
- 容量回升（SOH 超过 100%）通常是测试条件变化或数据错误，要单独指出。
