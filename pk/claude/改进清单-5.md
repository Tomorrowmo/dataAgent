# 改进清单-5：主页与对话页的 8 处调整

来源：对改进清单-4 实现结果的反馈（8 条）
分支：`feat/ui-redesign`

---

## 1. 「新建分析」和「分析」重复

**现状**：侧栏顶部的「新建分析」按钮和菜单里的「分析」都回到对话首页。

**改法**
- 去掉菜单里的「分析」。主菜单只剩：数据 / 流程。
- 在主页时，「新建分析」按钮显示为选中状态（白底 + 蓝色图标）。
- 在某个对话里时，「最近」列表里对应的那一条显示为选中状态，回到这个对话也从这里点。

## 2. 用示例数据和问题直接对话；说明写在所选问题下面

**现状**：点问题只填进输入框；没选数据时，提示出现在所有问题的最下面。

**改法**：选中的问题行展开，在问题文字下面显示：
```
升力线斜率、失速攻角、最大升阻比分别是多少？                    ›
需要：一组攻角扫描数据（攻角、CL、CD）
[用示例数据提问]   [用当前数据提问]
```
- **用示例数据提问**：载入这个问题对应的示例数据，并直接发送，进入对话。
- **用当前数据提问**：已选了数据时出现，把问题发到当前数据上；没选数据时这个按钮换成「用我的数据」，点了把问题填进输入框，并打开数据选择。
- 管理员新加的、没有配示例数据的问题，只显示「用我的数据」。
- 去掉列表最下面那条提示。

## 3. 支持格式的说明放回「导入数据」下面

按钮下面恢复第一版的文字：
> 可直接导入表格文件、Tecplot 导出文件、CGNS / VTK 等仿真结果，以及表格截图。其他格式会先生成读取程序，确认后保存，之后同类文件直接使用。

按钮上的悬停提示去掉，避免重复。

## 4. 侧栏与对话区之间的分割线；面板宽度可调

**现状**：侧栏和主页都是浅灰底，分割线颜色太淡，看不出界线。右侧工作台已经能拖动调宽度，但把手看不见；左侧菜单宽度固定。

**改法**
- 分割线加深一级（与工作台左边线同色）。
- 左侧菜单可拖动右边缘调宽度，范围 180–320px，记住上次的宽度。
- 两处拖动把手：鼠标移到边线上时出现蓝色细线和左右箭头光标，平时不显示。
- 双击边线恢复默认宽度。

## 5. 滚动条

**现状**：代码里设置了细滚动条，但没生效，界面上显示的是浏览器默认的粗滚动条。

**改法**
- 查清没生效的原因后，全局统一：宽 6px，圆角，滑块浅灰，鼠标移上去加深，轨道透明，不要上下箭头。
- 同时用标准写法（`scrollbar-width / scrollbar-color`），保证 Edge / Chrome / Firefox 一致。

## 6. 当前数据的位置，以及数据怎么组织

**现状**
- 主页上「当前数据」在输入框上方；进入对话后，数据选择跑到右上角顶栏。
- 输入框上方另有一条「下一条消息将接着上一步的结果继续」，和右上角的选择是两回事，但看起来都像"当前数据"。
- 系统里没有说明"源数据""中间结果""当前数据"分别是什么。

**先把概念定下来**（以后界面上的说法都按这四个词）

| 名称 | 含义 | 保存 |
|---|---|---|
| 分析 | 一次对话。从一组源数据开始，经过若干步处理，得到结论 | 长期 |
| 源数据 | 你导入的文件 | 长期，多个分析可以共用 |
| 中间结果 | 分析中每一步算法的输出，带运行编号，归属于产生它的分析 | 默认 20 天，可手动保留 |
| 当前数据 | 下一条消息要处理的数据：可以是源数据，也可以是上一步的中间结果 | — |

**改法：一个固定位置的「数据栏」**
- 主页和对话页都放在输入框正上方，去掉右上角顶栏里的数据选择。
- 合并原来的「接着上一步结果继续」提示条，一行说清楚：
```
源数据  NACA0012_α扫描.csv ×   重复吹风_02.csv ×   + 添加
当前处理  上一步结果「平滑」R-0012.2              改用源数据
```
  - 没有接续上一步时，第二行不显示，处理的就是源数据。
  - 点「源数据」旁边的 ⓘ 弹出上面四个概念的简短说明。
- 右侧工作台的「数据」页签改名为「本次分析的数据」：源数据在上，下面按步骤列出本次产生的中间结果（运行编号、算法、行×列），点开可查看。
- 数据页：核对现在的分组，确保分为「源数据」和「中间结果」两组，每组标题下一行说明保存规则。

## 7. 流程图里的算法显示中文名和说明

**现状**：右侧流程图的节点只显示函数名，比如 `savgol_filter`。

**改法**
- 节点显示「中文名」，下面一行小字是函数名，例如：
```
Savitzky-Golay 平滑
savgol_filter · window=11, order=3
```
- 鼠标移到节点上显示一句话说明（这个算法做什么）。
- 补齐内置算法的中文名和说明：现有 13 个，补上频谱分析、找峰值、标记峰值、聚类、线性回归、多项式回归、曲线拟合、转置、表达式计算、删除列、分箱、分组汇总共 12 个。
- AI 新建或用户自建的算法，显示它保存时的名称和说明。
- 同样的中文名也用在对话里的「本次分析步骤」列表中。

## 8. 提示类文字统一样式

**现状**：提示文字的字号、颜色各处不一（灰色深浅、大小都不同），和正文分不开层次。

**改法**：定一个统一的「提示」样式，全站替换。建议：
- 字号 12px，颜色用偏蓝的灰（与正文的中性灰区分开），不加粗；
- 单独成行的提示，前面加一个小的 ⓘ 图标；
- 跟在控件旁边的短提示，只换颜色和字号，不加图标。

覆盖范围：主页、对话页、数据页、设置页、流程页里的说明句、空状态提示、表单字段说明。错误提示保持红色，不属于这一类。

动手前我先做一个小样页，把正文、提示、错误三种文字放在一起给你看颜色，确认后再全站替换。

**已实施（2026-11-10，选 A）**：颜色 token `hint` = #5b7089；组件 `Hint`（components/ui.tsx）——单独成行的说明句带 ⓘ，空状态 / 控件旁短提示用 `text-xs text-hint` 不加图标。标签、数量、时间、编号、slug 不算提示，未改。
