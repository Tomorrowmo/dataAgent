# 改进清单-4：主页与左侧菜单改版

依据：`pk/claude/主页效果图-3.html`（已确认）
分支：`feat/ui-redesign`

## 目标

1. 主页说清楚三件事：能处理什么数据、能问什么问题、结果长什么样。
2. 减少边框，改用留白、细线、底色区分层次；只有结果卡片和输入框有阴影。
3. 左侧菜单从"图标 + 小字"的窄条改为带文字的浅色侧栏。
4. 文案按说明书写法：只写是什么、怎么用，不写口号、不用对比句。

## 第 2 步：主页

改 `web/components/ChatView.tsx` 中的 `Welcome`，替换上一版两栏主页。

**左栏**
- 标题"试验数据处理与分析"，下面一段说明：
  > 导入天平、传感器或采集系统导出的数据文件，用中文描述要做的处理，例如平滑、坐标转换、系数计算、频谱分析、曲线拟合。系统从算法库中选择方法执行，并在结果中记录输入文件、算法版本和参数。
- 两个按钮："打开风洞示例数据"、"导入数据"（悬停提示支持的格式）。
- 示例问题：页签按试验类型分（默认风洞试验 / 电池充放电 / 振动 NVH / 工艺参数 DOE，每类 4–6 个问题），内容来自第 3 步的配置。

**右栏：结果卡片**
- 点左边的问题，卡片换成该问题的示例结果：图表、2–4 个关键数值、处理链路。
- 示例结果是静态内容（内置问题预先做好；管理员新加的问题来自第 3 步的快照），不在打开主页时实时计算。
- 用户已有自己的结果时，第一个页签前加"我的最近结果"，默认显示用户最近一次分析的结果，"查看运行记录"跳到对应对话。

**点击问题后的行为**
- 已选数据：把问题填进输入框，不自动发送。
- 未选数据：提示"先选择数据，或使用该类型的示例数据"，可一键载入对应示例数据并填好问题。

**整页**
- 同一底色；顶部网格向下淡出；内容在可用高度内上下居中。
- 输入框改为浮起的卡片，去掉上边框；上方"当前数据"用小标签显示。
- 去掉上一版的右栏（我的数据 / 最近的分析 / 我的流程）：最近对话移到左侧菜单，数据和流程在各自页面。

**验收**：1920 / 1440 / 1100 / 手机四个宽度截图；新用户、已有数据但无结果、已有结果三种状态都不空、不错位；四个页签的问题都能点。

## 第 3 步：示例问题可增加、修改（管理员维护）

所有用户看到同一套示例问题，由管理员在「设置 → 主页示例问题」里维护。

**能改什么**
- 页签：增加、改名、排序、隐藏（比如加一个「结构静力试验」）。
- 问题：增加、改文字、排序、隐藏；可以填"需要的数据"说明（未选数据时提示用）。
- 内置的风洞 / 电池 / 振动 / 工艺参数问题也可以改或隐藏；提供"恢复默认"。

**新加问题的示例结果：从运行记录里挑**
- 编辑问题时点"选择示例结果"，列出管理员自己的运行记录（运行编号、算法、时间）。
- 选中后，服务器把展示需要的内容复制一份存进配置，以后与原记录无关：
  - 图表：管理员选横轴和 1–3 条纵轴，数据抽样到不超过 500 点；
  - 处理链路：输入数据名、各步算法与版本、参数（取自运行记录）；
  - 关键数值：0–4 个，管理员手填（名称 / 数值 / 单位 / 备注）。
- 复制而不是引用，是因为运行结果只有本人能读（第 0 步的归属限制），普通用户读不到管理员的文件；原记录被清理后示例也不受影响。
- 不选示例结果：卡片显示问题、需要的数据和会用到的方法说明。

**后端**
- 配置存在 `app_settings` 表，键 `home_examples`，JSON。未配置时返回内置默认。
- `GET /api/home/examples`：所有登录用户可读。
- `PUT /api/home/examples`：仅管理员，保存前校验结构和长度（页签 ≤ 8，每页签问题 ≤ 12，示例快照总大小 ≤ 200 KB）。
- `POST /api/home/examples/snapshot`：仅管理员，参数 `run_id`、横轴列、纵轴列，返回快照；只能选自己的运行记录。
- 内置问题的示例结果仍在前端代码里，配置中用 `builtin_key` 引用。

**验收**：管理员加页签、加问题、挑运行记录做示例结果后，普通账号刷新主页能看到；原运行记录被清理后示例仍正常显示；普通用户调用 PUT / snapshot 返回 403；后端测试覆盖这三个接口。

## 第 4 步：风洞示例数据与"打开风洞示例数据"

现有示例数据由前端生成（`web/lib/recipes.ts` 的 `STARTERS`），风洞数据沿用这个做法。

新增示例数据（数值与效果图卡片一致）：

| 名称 | 内容 |
|---|---|
| 示例·风洞攻角扫描 | α −4°~20°，CL / CD / Cm，第 1 次吹风 |
| 示例·风洞重复吹风 | 同工况第 2 次吹风 |
| 示例·风洞雷诺数对比 | Re 2×10⁵ / 3×10⁵ / 5×10⁵ 三组 CL |
| 示例·脉动压力 | 测点 P05 时间序列，主频 62.4 Hz |
| 示例·测点通道 | 12 个测点，P05、P10 偏差异常 |

"打开风洞示例数据"：
- 有大模型配置：载入攻角扫描数据，并发送第一个风洞问题。
- 没有大模型配置：用内置算法直接算出升力线斜率（`linear_regression`）、失速攻角（取 CL 最大值）、最大升阻比（`derived_column` 算 CL/CD 后取最大值），结果显示在卡片里。替代现在的周期信号 FFT 演示。

频谱示例按普通 FFT（`fft_frequency_analysis`）写，不新增 Welch 算法（已确认 A）。

**验收**：新账号点"打开风洞示例数据"，有 / 无大模型两种情况都能得到结果，数值与卡片一致。
