## 3. 数据页分层

### 现状
数据页一进去所有东西都摆在一起：
- 左栏：上传大按钮 + 格式说明 + 「清理中间结果」 + 3 个筛选 + 3 个勾选 + 说明文字 + 数据树（源数据和中间结果混在一棵树里）；
- 右栏：直接打开某一份数据的详情，同时有：即将清理提醒、产生于（运行编号 / 重跑 / 复现）、数据概况、「可以这样做」、血缘、保留 / 升为正式数据集、字段结构。

导入管理、溯源管理、数据详情三件事挤在同一屏，层次不清。

### 要不要把「数据」和「溯源」分成两个菜单？
**建议不分成两个菜单，在数据页里分成两个页签。** 理由：
- 源数据和中间结果是同一种东西（都是表），用户找数据时不应先判断它算哪一类；
- 溯源是中间结果的一个属性（它从哪来），不是独立的对象；分到另一个菜单，看一份结果要在两处来回跳；
- 「清理、保留、即将过期」只和中间结果有关，放进中间结果页签就够了，源数据页签保持干净。

### 改法：三层
**第一层：列表（进入数据页时）**
```
数据                                                   [导入数据]
源数据是你导入的文件，长期保存；中间结果是分析中每一步的输出，带运行编号，默认保留 20 天。

[ 源数据 8 ]  [ 中间结果 24 · 1 份即将清理 ]

名称                      行×列      导入时间   用于分析   中间结果
示例·风洞攻角扫描          25×4       11-09      2 个       3 份
示例·脉动压力              8000×2     11-10      1 个       4 份
…
```
- 「源数据」页签：只有导入的文件，一行一份；右上角「导入数据」打开导入对话框，支持格式写在对话框里，不再常驻页面。
- 「中间结果」页签：按分析（对话）分组，每组列出各步结果（运行编号、算法中文名、行×列、到期时间、是否保留）；筛选（即将清理 / 已保留 / 已清理）、即将清理的提醒条和「清理中间结果」按钮都只在这个页签里。

**第二层：数据详情（点一行进入，整页）**
```
← 源数据 / 示例·脉动压力
示例·脉动压力   8000 行 × 2 列   导入于 11-10            [在对话中分析] [导出]
[ 预览 ]  [ 字段 ]  [ 来源与血缘 ]  [ 用在哪些分析 ]
```
- 预览：数据表 + 自动生成的数据概况 + 「可以这样做」。
- 字段：字段结构表。
- 来源与血缘：源数据显示文件名和导入时间；中间结果显示产生于哪个分析、哪一步、算法和参数，以及重跑 / 复现、保留 / 升为正式数据集。
- 用在哪些分析：列出用到它的对话，点了回到对话。

**第三层：操作**：重跑、复现、清理、AI 整理等，从详情页里的按钮进入，不在列表上直接暴露。

**已实施（2026-11-10）**：按 pk/claude/数据页效果图.html，改为左列表（源数据 / 中间结果两个页签，中间结果按分析分组、带状态筛选）+ 右侧概览 / 详情（预览 · 字段 · 来源（与血缘） · 用在哪些分析）。去掉了时间 / 来源 / 算法三个筛选，搜索可查名称、列名、运行编号。后端未改。

## 4. 流程、算法、技能三个页面统一

### 现状
| 页面 | 进入时看到的 |
|---|---|
| 流程 | 直接打开第一个流程的编辑画布（左侧流程列表、中间算法库、右侧画布） |
| 算法 | 左侧算法列表，右侧一段说明 |
| 技能 | 一段介绍 + 拖放上传区 + 「我的 Skills」+「平台默认」卡片 |

三种进入方式各不相同；流程页一进去就是最重的编辑界面。

### 建议：同一套「库首页 → 详情 → 编辑」结构（技能页现在最接近，以它为样板）

**库首页（进入时）**，三个页面同一个版式：
```
流程                                                      [新建流程]
流程是保存下来的分析步骤，可以用在新的数据上一键重跑，不经过 AI。
在对话回答末尾点「存为流程」也能保存。

[搜索…]   全部 · 我的 · 示例

┌───────────────────────┐ ┌───────────────────────┐ ┌──────────────
│ 平滑后看频谱           │ │ 质量清洗 + 相关分析     │ │ …
│ Savitzky-Golay 平滑 →  │ │ 数据清洗 → 异常值检测   │ │
│ FFT 频谱分析           │ │ → 相关性矩阵            │ │
│ 2 步 · 上次运行 11-09  │ │ 3 步 · 示例             │ │
│          [运行] [编辑] │ │          [运行] [编辑]  │ │
└───────────────────────┘ └───────────────────────┘ └──────────────
```
- **流程**：入口「新建流程」；卡片显示步骤链（算法中文名）、步数、上次运行时间；按钮「运行」（选数据后运行）、「编辑」（进入现在的画布）。
- **算法**：入口「上传自由算法」「AI 生成算法」；卡片按类别分组（准备清洗 / 平滑去噪 / 找特征 / 拟合建模 / 降维 / 结构操作），每张卡片是中文名 + 一句说明 + 来源标签（内置 / 我的 / AI 生成）；点卡片进入现在的算法详情（参数、试运行、代码编辑、版本）。
- **技能**：保留现有内容，只把标题区改成同一版式（标题 + 介绍 + 右上角入口），上传区收进「添加技能」对话框。

**详情 / 编辑页**：点卡片进入，就是现在的详细操作界面；顶部加面包屑「流程 / 平滑后看频谱」，可返回库首页。

**统一规则**
- 标题区：标题 + 不超过两行的介绍 + 右上角主操作按钮；
- 卡片：同一种尺寸和样式，信息顺序为 名称 → 一句话说明 → 关键信息 → 操作；
- 空状态：写清楚怎么得到第一个（例如流程：「在对话回答末尾点"存为流程"」）；
- 数据页也按同一结构：列表（两个页签）→ 详情 → 操作。

**需要注意**
- 算法页里「AI 共创」的对话和代码编辑在切换页面时要保持不丢（现在靠页面常驻实现），改版时保留这个行为。
- 流程画布从「一进去就打开」变成「点编辑才打开」，多了一次点击；但首页卡片上能直接「运行」，常用操作反而更短。
